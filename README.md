Smart Pantry Manager
Project Overview
Smart Pantry Manager is a android mobile application designed to help users manage pantry ingredients and discover recipes using ingredients they have available.
Main features
1.Add and manage pantry ingredients
2. Record ingredient quantities and expiry dates
3.View available recipes
4.Check the ingredients required for each recipe
5.Store pantry and recipe information using an SQLite database
Technologies Used
1.Android Studio
2.SQLite Database
3.Android SDK
4.Git and Github
Database
The application uses an SQLite database to store pantry ingredients, recipes and recipe ingredients.
